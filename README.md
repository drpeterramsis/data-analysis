# Dr. Peter Ramsis — Learning Hub

Static GitHub Pages website.

- `index.html`: bilingual landing page (Arabic default)
- `tableau/index.html`: complete Tableau study guide, Arabic explanations with English Tableau terminology, English chapter labels, and actual Tableau screenshots from the lecture slides

## Deploy
Upload the **contents** of this directory to the repository root. Then GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Landing: `https://drpeterramsis.github.io/data-anlysis/`
Tableau: `https://drpeterramsis.github.io/data-anlysis/tableau/`

## Important
The Tableau guide is not a fully translated English textbook: the original detailed lessons are Arabic; English mode adds English navigation and labels. Some educational drawings are recreations, not screenshots; actual Tableau screenshots are explicitly labeled.
